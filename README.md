# Portfolio de Diclem Alexander

## Publicar en GitHub Pages

1. Descomprime el ZIP.
2. Sube **el contenido** a la raíz del repositorio: `index.html`, la carpeta `assets` completa y los demás archivos. No subas el ZIP ni encierres todo dentro de otra carpeta.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**. Guarda.
4. Abre la dirección que GitHub indique al terminar el despliegue.

Las rutas son relativas, por lo que las imágenes funcionan también si el sitio está dentro de la ruta de un repositorio.
